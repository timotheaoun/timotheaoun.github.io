Créer un grapheur en python sans bibliothèques ?


Introduction...

Maplotlib. C'est le premier résultat qu'on obtient quand on recherche "bibliothèque python pour créer grapheur". Avec cette bibliothèque, on peut littéralement créer un graphe en 7 lignes

python 
import matplotlib.pyplot as plt
x = [1, 2, 3, 4]
y = [10, 20, 25, 30]
plt.plot(x, y)
plt.xlabel("X")
plt.ylabel("Y")
plt.show()

Mais nous, on cherche à savoir comment marche maplotlib, c'est pourquoi, nous allons créer une bibliothèque très simple pour tracer une fonction... Et c'est là que tout va se compliquer...
